## Security and reliability

PLATINEXOS 1.0.0 is a free, independent application developed to track games, achievements and progress on Steam.

Before release, the application underwent functional tests, integrity checks and security analyses by specialized platforms.

**Security analysis results:**

- **VirusTotal:** none of the 60 antivirus engines detected threats in the analyzed package (0/60).
- **Kaspersky OpenTIP:** the file was classified as **Clean**.
- **OPSWAT MetaDefender:** no detections among the 21 antivirus engines shown (0/21), with an overall result of **No Threats Detected**.

The package also underwent technical inspection of its components and dependencies, with no malicious behavior identified that required changes to the application.

PLATINEXOS does not ask for Steam passwords or Steam Guard codes. Steam integration uses a personal Steam Web API key, with optional secure storage in Windows Credential Manager.

The platform reports are available for consultation. The official SHA-256 allows users to verify the integrity of the distributed file by comparing it with the approved original package.
